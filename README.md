# Maths Solution Ebook Databank

Interactive solution ebooks for iPad and Apple Pencil. Each book takes a chapter's question notes (QUE PDF) and the teacher's answer notes (ANS PDF), and turns them into a web ebook:

- the original QUE pages are the background, so the design is unchanged;
- step-by-step solutions that follow the teacher's method sit in the blank answer spaces, revealed one tap at a time;
- review links connect key words in the question to the matching parts of the answer;
- interactive graphics open beside questions where a picture helps;
- an annotation layer works like Notability: pen, highlighter, eraser, laser, select and edit, undo by two-finger tap, presentation mode.

Live site: <https://uniplusmathsteam-bot.github.io/jm26b-inequalities-ebook/>. Its front page is the library, and each card opens one book.

## Folder map

```text
index.html            library (front page): lists every book in books/catalog.json
reader.html           the ebook reader; opens reader.html?book=<id>
sw.js, manifest.webmanifest, assets/   offline app shell and icons (shared)
engine/               the shared reader, used by every book; you rarely edit it for a new chapter
  book.js             loads the chosen book (book.json, layout.json, solutions.js, widgets.js)
  authoring.js        helpers used in solutions.js: m, t, h, note, nl, L, lk
  viewer/             pages, answer boxes, step reveal, review links, presentation mode
  ink/                Apple Pencil ink, shapes, selection, eraser, replay
  export/             PDF and ink-file export
  widgets/kit.js      drawing kit for interactive graphics
  styles.css
books/
  catalog.json        which books the library shows
  _template/          starting files for a new book
  <id>/
    book.json         chapter details, sections, question list, region overrides
    layout.json       generated by tools/extract_pages.py: never edit by hand
    pages/p01.jpg …   generated page images
    solutions.js      the worked solutions (written for each chapter)
    widgets.js        the interactive graphics (written for each chapter)
    source/           QUE and ANS PDFs (kept out of git)
    reference/        teacher-solution crops and QA screenshots (kept out of git)
tools/
  new_book.py         create books/<id> from the template and add it to the catalog
  extract_pages.py    render pages and find answer regions (--scan drafts the question list)
  extract_ans_refs.py crop the teacher's red-boxed working from the ANS PDF
  qa/check_book.mjs   emulated-iPad checks and screenshots for one book
vendor/               KaTeX, perfect-freehand, pdf-lib (offline copies)
docs/                 how to build and maintain books (start with 01-workflow.md)
```

## Quick start

Preview on this computer (the app needs a web server; opening the file directly does not work):

```powershell
python -m http.server 8090
```

Then open <http://127.0.0.1:8090/>.

Add a chapter: follow [docs/01-workflow.md](docs/01-workflow.md). In short:

```powershell
python tools/new_book.py jm27a --form S3 --code "JM27 (A)" --title "…" --que "…QUE.pdf" --ans "…ANS.pdf"
python tools/extract_pages.py jm27a --scan        # draft the question list for book.json
python tools/extract_pages.py jm27a               # pages + layout.json
python tools/extract_ans_refs.py jm27a            # teacher's working, for writing solutions
# write books/jm27a/solutions.js and widgets.js
cd tools/qa; npm install; node check_book.mjs jm27a --shots
```

Needs Python 3 with PyMuPDF (`pip install pymupdf`), Node 18+ and Google Chrome (for QA only).
